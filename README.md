# 🎵 Music Flow

A powerful, high-performance Telegram Voice Chat Music Bot built with **Pyrogram**, **PyTgCalls**, and **youtube-search-python**.

## ✨ Features
- **Fast Low-Latency Audio Streaming:** High-fidelity voice chat streaming with buffer-free playback.
- **Smart AutoPlay Mode (`/autoplay`):** Continuous infinite stream playing YouTube related tracks.
- **Interactive Recommendations:** When AutoPlay is OFF, displays 3 instant-play song buttons + 1 "More Songs" pagination button upon track completion.
- **Clean Aesthetic Interface:** Distraction-free design with only an official Channel link.
- **100% URL-Based Configuration:** All images and banners load directly via URLs without local disk clutter.
- **Comprehensive Administration:** Admin controls, sudo management, auth users, blacklisting, broadcasting, and real-time server statistics.

## 🚀 Quick Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/MusicFlowBot.git
   cd MusicFlowBot
   ```
2. Copy sample environment file and configure credentials:
   ```bash
   cp sample.env .env
   ```
3. Install dependencies and run:
   ```bash
   pip3 install -U -r requirements.txt
   bash start
   ```
